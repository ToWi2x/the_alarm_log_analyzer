"""# The SECOM Alarm Log Analyzer

This Python project is a data pipeline designed to ingest, clean, and report on security sensor events. It demonstrates fundamental backend concepts including file handling, object-oriented programming, and conditional data filtering.

## Overview
The script processes raw sensor log files (`.csv`), filters out non-essential "false alarm" events based on specific business logic, and generates a clean report for further analysis.

## Project Structure
- `realm_alarm.py`: The main execution script containing the `AlarmEvent` class, the `parse_logs` function, and the `filter_alarms` logic.
- `secom_alarms.csv`: The input file containing raw sensor event data.
- `valid_alarms_report.csv`: The output file generated by the script containing only validated alarms.

## Features
- **Data Modeling**: Uses an `AlarmEvent` class to represent and structure sensor data.
- **Data Parsing**: Safely reads and converts CSV data into manageable Python objects.
- **Intelligent Filtering**:
    - **Cat Filter**: Ignores short motion events (< 3s).
    - **Glitch Filter**: Ignores short door events (< 3s).
    - **Maintenance Filter**: Filters out any sensors in `offline` status.
- **Reporting**: Generates a summary report of valid alarms.

## How to Run
1. Ensure you have Python installed.
2. Place `realm_alarm.py` and `secom_alarms.csv` in the same directory.
3. Execute the script via terminal:
   ```bash
   python realm_alarm.py
